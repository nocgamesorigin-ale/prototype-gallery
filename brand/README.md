# brand/

Đặt 2 file ảnh vào đây rồi push — site tự cập nhật sau ~1 phút.

| File | Dùng ở đâu | Gợi ý |
|---|---|---|
| `logo.png` (hoặc .jpg/.webp/.svg) | Màn đăng nhập, góc trái header, icon tab trình duyệt | Vuông, ≥ 256×256, nền trong suốt |
| `team.jpg` (hoặc .png/.webp) | Ảnh team nổi bật ở trang Giới thiệu | Ngang 4:3, ~1600×1200, ≤ 5 MB |

- Logo **không** mã hoá (màn đăng nhập cần hiện trước khi có mật khẩu).
- Ảnh team **được mã hoá** như game — chỉ người có mật khẩu mới xem được.
- Không có file nào thì site dùng icon mặc định và khung "Ảnh team" trống.
